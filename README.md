# π0.5 FR3 Reproduction

Real-world reproduction of π0.5 on Franka robots based on the OpenPI framework.

## Overview

This project focuses on deploying and fine-tuning π0.5 policies on real Franka Research 3 robots using VR teleoperation data collection.

The project includes:

* VR teleoperation system
* Real-world data collection
* HuggingFace dataset construction
* LoRA fine-tuning
* Real-time inference deployment
* Dual-arm manipulation experiments
